# Go_Kuzin_Ivan
# Веб-приложение «Учёт личных трат» 📊

Семестровый проект по разработке веб-приложения на языке **Go (Golang)**, предназначенный для ведения истории расходов, контроля бюджета и анализа затрат. Проект реализован в рамках выполнения лабораторных работ (Этапы 1 и 2).

## 🚀 Функционал проекта
* **Маршрутизация запросов (Routing):** Использование встроенного маршрутизатора `http.NewServeMux` для обработки страниц проекта.
* **Потокобезопасность:** Безопасная работа с данными в оперативной памяти из разных потоков (горутин) с помощью мьютексов (`sync.Mutex`).
* **HTML-интерфейс:** Отрисовка динамических веб-страниц с использованием стандартного шаблонизатора `html/template`.
* **Защита от дублирования данных:** Реализация паттерна проектирования **Post/Redirect/Get (PRG)** для предотвращения повторной отправки формы при обновлении страницы (F5).
* **Валидация данных:** Строгая проверка вводимых пользователем сумм (число больше нуля) и текстовых описаний.

## 📁 Структура проекта
Проект построен по стандартной и общепринятой архитектуре приложений на Go:
```text
tracker/
├── cmd/
│   └── server/
│       └── main.go       # Точка входа, запуск HTTP-сервера и маршрутизация
├── internal/
│   ├── handlers/
│   │   └── handlers.go   # Бизнес-логика сайта, обработка HTTP-запросов и форм
│   └── models/
│       └── models.go     # Описание структур данных (модель Expense)
├── web/
│   └── templates/
│       ├── layout.html   # Базовый каркас сайта (шапка, подвал, стили)
│       └── index.html    # Главная страница (форма ввода и таблица расходов)
└── go.mod                # Файл конфигурации модулей Go
```

## 🛠️ Описание реализованных эндпоинтов (ЭТАП 1)
1. `GET /` — Главная страница приложения, отображающая форму добавления расходов и общую таблицу с историей трат.
2. `POST /` — Обработчик формы. Принимает данные, валидирует их и сохраняет в массив трат.
3. `GET /about` — Информационная страница с описанием семестрового проекта.
4. `GET /ping` — Технический эндпоинт для проверки работоспособности сервера. Возвращает текстовый статус `pong` строго на методы типа `GET`. На любые другие методы возвращает `405 Method Not Allowed`.

## 📦 Используемые технологии и паттерны (ЭТАП 2)
* **Язык разработки:** Go (версия 1.27.1)
* **Архитектурный подход:** Разделение проекта на слои (Точка запуска `cmd`, логика обработки `handlers`, структуры данных `models` и слой представления `web`).
* **Конкурентность:** Использование `sync.Mutex` для предотвращения race condition при конкурентной записи расходов несколькими пользователями.

## 🏁 Инструкция по локальному запуску
Для запуска проекта необходимо находиться в корневой директории приложения (там, где расположен файл `go.mod`) и выполнить следующую команду в терминале:

```bash
go run ./cmd/server/main.go
```

После успешного запуска сервер начнет работу на порту `8080`. Откройте браузер и перейдите по адресу:
```text
http://localhost:8080
```
