# Go_Kuzin_Ivan
# Семестровый проект: Учёт личных трат (Этапы 1-3)

Лабораторная работа по веб-разработке на Go. Приложение представляет собой локальный веб-сервер для фиксации и просмотра истории расходов.

### Что сделано по этапам:
* **Этап 1-2:** Настроен запуск HTTP-сервера на порту :8080. Реализована обработка страниц `/`, `/about` и эндпоинта `/ping` (работает строго на GET). Сделан рендеринг HTML-шаблонов и базовая валидация данных из формы (проверка суммы и пустого описания). Добавлен редирект для защиты от повторной отправки данных при обновлении страницы (F5).
* **Этап 3:** Подключена база данных SQLite через CGO-free драйвер modernc.org/sqlite. Вся работа с данными вынесена в отдельный слой репозитория (`internal/repository`), хендлеры полностью отвязаны от SQL-запросов. Реализована автоматическая инициализация таблиц из SQL-скрипта при старте. Данные теперь сохраняются в файл на диске и не стираются при перезапуске сервера.

### Архитектура проекта:
* `cmd/server/main.go` — точка входа, подключение к бд, запуск миграций и сервера.
* `internal/handlers/` — хендлеры страниц (`handlers.go`) и структура данных расходов (`expense.go`).
* `internal/repository/expense.go` — слой работы с базой данных (методы Create и GetAll).
* `migrations/init.sql` — SQL-скрипт для создания таблицы расходов при первом запуске.
* `web/templates/` — шаблоны страниц (layout.html и index.html).

### Инструкция по запуску:
1. Выполнить команду для загрузки зависимостей (драйвера sqlite):
   go mod tidy

2. Запустить сервер из корня папки проекта:
   go run personal-expenses/cmd/server

После этого приложение доступно в браузере по адресу: http://localhost:8080
При первом старте в корне проекта автоматически создастся файл базы данных expenses.db.
