# Go_Kuzin_Ivan
# Семестровый проект: Учёт личных трат (Этапы 1-5)

Лабораторная работа по веб-разработке на Go. Приложение представляет собой многопользовательский веб-сервер для фиксации и просмотра истории расходов с авторизацией и фильтрами.

### Что реализовано по этапам:
* **Этап 1-2:** Настроен HTTP-сервер на порту :8080. Реализована обработка страниц `/`, `/about` и `/ping` (работает строго на GET). Сделан рендеринг HTML-шаблонов и базовая валидация данных из формы. Добавлен редирект для защиты от повторной отправки данных при обновлении страницы (Паттерн PRG).
* **Этап 3:** Подключена база данных SQLite через CGO-free драйвер modernc.org/sqlite. Вся работа с данными вынесена в слой репозитория, хендлеры получают зависимости через структуру-конструктор. Реализована автоматическая построчная инициализация таблиц из SQL-скрипта при старте.
* **Этап 4:** Создана таблица-справочник categories с базовыми категориями (Еда, Транспорт, Жилье и др.). В таблицу расходов добавлено поле category_id. Вывод списка трат переписан через LEFT JOIN. Реализована динамическая фильтрация трат на главной странице по категориям и диапазону дат (от/до) через query-параметры. Если фильтры пустые — выводится полный список.
* **Этап 5:** Реализована регистрация и вход пользователей. Пароли хэшируются через SHA-256. Авторизация работает на сессиях в БД и куках (session_id). Написано защитное middleware, блокирующее доступ к тратам для неавторизованных юзеров. В таблицу трат добавлено поле user_id — каждый пользователь видит, редактирует и удаляет строго свои расходы. Реализован выход из системы (инвалидация сессии и удаление куки).

### Архитектура проекта:
* `cmd/server/main.go` — точка входа, подключение к бд, миграции, middleware и запуск сервера.
* `internal/handlers/handlers.go` — хендлеры авторизации, страниц и CRUD-операций трат.
* `internal/repository/expense.go` — слой работы с БД (пользователи, сессии, расходы с фильтрами и JOIN).
* `internal/models/models.go` — структуры данных (User, Category, Expense).
* `migrations/init.sql` — SQL-скрипт для создания структуры таблиц и дефолтных категорий.
* `web/templates/` — HTML-шаблоны страниц (layout, index, edit, auth).

### Инструкция по запуску:
1. Выполнить команду для загрузки зависимостей (драйвера sqlite):
   go mod tidy

2. Запустить сервер из корня папки проекта:
   go run personal-expenses/cmd/server

После этого приложение доступно в браузере по адресу: http://localhost:8080
При первом старте автоматически создастся файл базы данных expenses.db с базовыми категориями.
